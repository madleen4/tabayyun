# تَبَيَّن | TABAYYUN

**تثبّت من صحة الأحاديث قبل نشرها.**

تَبَيَّن أداة ويب تساعد صانع المحتوى على فحص النصوص قبل نشرها.  
يلصق المستخدم نصًا أو يرفع ملفًا، فيستخدم النظام الذكاء الاصطناعي لاستخراج الأقوال المنسوبة إلى النبي ﷺ، ثم يتحقق منها بالرجوع إلى المصادر الحديثية، ويعرض حالة الحديث ومصدره وأحكام المحدّثين، ويكشف اختلاف اللفظ، ويساعد المستخدم على إخراج نص موثق قبل النشر.

مشاركة في **تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي**  
**المسار (04): أدوات المعرفة والتحقق لتمكين المعرّفين بالإسلام.**

## روابط المشروع

- **Live Demo:** https://tabayyun-oats.onrender.com
- **GitHub:** https://github.com/madleen4/tabayyun
- **صفحة اختبار الحالات:** https://tabayyun-oats.onrender.com/cases.html

> تَبَيَّن أداة مساعدة وليست مرجعًا شرعيًا، ولا تُصدر حكمًا شرعيًا من عندها. نصوص الأحاديث وأحكام المحدّثين تأتي من المصادر، بينما يُستخدم الذكاء الاصطناعي للاستخراج والمهام اللغوية المساندة.

# المشكلة

قد تنتشر نصوص منسوبة إلى النبي ﷺ وهي:

- ضعيفة.
- موضوعة.
- منقولة بلفظ مختلف عن المصدر.
- أو غير موجودة أصلًا بالصورة المتداولة.

التحقق اليدوي يتطلب من صانع المحتوى:

1. تحديد كل حديث في النص.
2. البحث عنه منفردًا.
3. الرجوع إلى المصادر.
4. معرفة حكم المحدّثين.
5. مقارنة اللفظ المتداول بلفظ المصدر.
6. إعادة كتابة النص وتوثيقه.

كما أن الاعتماد على نموذج لغوي عام وحده قد يؤدي إلى توليد حكم أو مصدر غير موثق.

لذلك يفصل تَبَيَّن بين:

**الذكاء الاصطناعي للاستخراج والفهم اللغوي**  
و  
**المصادر الحديثية للحكم والنص والتوثيق.**

# آلية العمل

| الخطوة | ما يحدث |
| --- | --- |
| 1. الإدخال | يلصق المستخدم نصًا أو يرفع ملف Word / PDF / صورة. |
| 2. استخراج الأحاديث | يستخدم Gemini لاكتشاف الأقوال المنسوبة إلى النبي ﷺ داخل النص دون الحكم عليها. |
| 3. التحقق من الحديث الثابت | يبحث النظام أولًا في HadeethEnc عن الحديث والمطابقة مع النص الموثق. |
| 4. التحقق من بقية الحالات | إذا لم يثبت الحديث عبر HadeethEnc، يبحث النظام في أحكام المحتوى الحديثي عبر API الباحث الحديثي. |
| 5. تحديد الحالة | تحوّل قواعد النظام نتائج المصادر إلى الحالات التي تعرضها الواجهة. |
| 6. كشف اختلاف اللفظ | يقارن نص المستخدم بلفظ المصدر عند توفر تطابق موثوق. |
| 7. عرض المصادر | تظهر بيانات المصدر والحكم ومعلومات التخريج المتاحة. |
| 8. الإجراء النهائي | يختار المستخدم الإبقاء أو الحذف أو الاستبدال بحسب النتيجة. |

# ربط الذكاء الاصطناعي بالتقنيات

مسار البيانات في المشروع:

```text
المستخدم
   ↓
واجهة تَبَيَّن
HTML / CSS / JavaScript
   ↓
Node.js Server
   ↓
Gemini API
استخراج الأقوال المنسوبة للنبي ﷺ
   ↓
HadeethEnc
التحقق من الحديث الثابت والنص الموثق
   ↓
عند الحاجة
API الباحث الحديثي
أحكام المحدّثين ومعلومات التخريج
   ↓
قواعد التصنيف والمطابقة
   ↓
بطاقة النتيجة
الحالة + المصدر + اختلاف اللفظ + الإجراء المقترح
```

## دور Gemini

Gemini لا يُستخدم كمصدر لحكم صحة الحديث.

يُستخدم في:

- استخراج الأقوال المنسوبة للنبي ﷺ من النص الحر.
- التعامل مع النص الموجود في الصور عند استخدام ميزة القراءة.
- فهم السياق اللغوي.
- المساعدة في صياغة استعلامات البحث عند الحاجة.

ولا يُستخدم في:

- إنشاء حكم صحة الحديث.
- اختراع مصدر.
- كتابة حديث جديد.
- تغيير نص الحديث القادم من المصدر.

القاعدة الأساسية:

> **الذكاء الاصطناعي يستخرج، والمصادر الحديثية تتحقق.**

# حالات التحقق

يعرض تَبَيَّن الحالات التالية:

### ثابت

تم العثور على الحديث في المصدر المستخدم للأحاديث الثابتة مع مطابقة موثوقة.

### ضعيف

وردت في النتائج أحكام للمحدّثين بتضعيف الحديث أو إسناده.

### موضوع

ورد حكم بالوضع أو البطلان أو عدم الأصل بحسب النتائج المسترجعة من المصدر.

### مختلف فيه

عندما تعيد المصادر أحكامًا مختلفة يصنفها النظام ضمن أكثر من حالة، تعرض الأداة اختلاف الأحكام دون أن تصدر ترجيحًا شرعيًا من عندها.

### لم يُعثر عليه

نجحت عملية البحث تقنيًا، لكن لم يتم العثور على أصل مطابق بثقة كافية.

### تعذّر التحقق

حالة تقنية منفصلة تظهر إذا تعذر الوصول إلى المصدر المطلوب.

**تعذّر المصدر لا يتحول إلى حكم شرعي على الحديث.**

# المصادر الشرعية والمعرفية

## 1. موسوعة الأحاديث النبوية — HadeethEnc

الموقع:

https://hadeethenc.com/ar/

توثيق الـ API:

https://hadeethenc.com/api-docs/

### استخدامه داخل تَبَيَّن

يستخدم المشروع HadeethEnc من أجل:

- البحث عن الأحاديث الثابتة.
- مطابقة نص المستخدم بحديث موثق.
- الحصول على النص الموجود في المصدر.
- دعم البحث عن البدائل الثابتة عند توفرها.

تُنسب النتائج إلى المصدر، ولا يفترض النظام أن نصًا ولّده الذكاء الاصطناعي هو نص حديث.

---

## 2. الموسوعة الحديثية — الدرر السنية

الموقع:

https://dorar.net/

تستخدم أحكام المحدّثين وبيانات التخريج الموجودة في المحتوى الحديثي للتحقق من الحالات التي لم تثبت في المسار الأول.

ومن أمثلتها:

- الضعيف.
- الموضوع.
- الأحكام المختلفة بين المحدّثين.

---

## 3. API الباحث الحديثي

العنوان المستخدم حاليًا:

https://search.sunnah.one/

يستخدم المشروع هذه الواجهة كطبقة وصول تقنية لنتائج البحث الحديثي التي تتضمن:

- نص الحديث.
- الحكم.
- المحدّث.
- المصدر.
- معلومات التخريج.

> لا يقدم المشروع `search.sunnah.one` على أنه API رسمي تابع لموقع الدرر السنية، وإنما باعتباره واجهة الوصول التقنية المستخدمة حاليًا في التطبيق إلى نتائج المحتوى الحديثي.

- لا تعرض نتيجة دينية بلا مصدر عندما تكون بيانات المصدر متوفرة.
- لا يولّد Gemini درجة الحديث.

- تعطل الخدمة يظهر كخطأ تقني مستقل.
- عند وجود أحكام مختلفة، تعرض الأداة النتائج دون ترجيح شرعي من عندها.

شعار المشروع:

> **كل نتيجة لها مصدر، وكل حكم له قائل.**

# بنية المشروع

أهم الملفات والمجلدات:

```text
tabayyun/
│
├── public/
│   ├── index.html
│   ├── cases.html
│   ├── pipeline.js
│   └── dorar-client.js
│
├── src/
│   ├── gemini.js
│   ├── hadeethenc.js
│   ├── classify.js
│   ├── match.js
│   └── normalize.js
│
├── server.js
├── package.json
├── README.md
└── .env
```

### `server.js`

الخادم الرئيسي للمشروع وربط الواجهة بالخدمات الخلفية.

### `src/gemini.js`

منطق الاتصال بـ Gemini واستخراج النصوص المنسوبة للنبي ﷺ.

### `src/hadeethenc.js`

التكامل مع HadeethEnc.

### `public/dorar-client.js`

الاتصال بواجهة الباحث الحديثي المستخدمة لجلب نتائج المحتوى الحديثي.

### `src/classify.js`

تحويل الأحكام المسترجعة إلى الحالات التي تعرضها واجهة تَبَيَّن.

### `src/match.js`

المطابقة وقياس التشابه بين النصوص.

### `src/normalize.js`

تطبيع النص العربي لدعم البحث والمقارنة.

### `public/pipeline.js`

تنسيق خطوات التحقق وعرض النتائج في الواجهة.

# التعامل مع الأخطاء

## فشل Gemini

إذا تعذر تحليل النص بواسطة Gemini، يعرض النظام حالة فشل واضحة ولا يقدم استخراجًا آخر على أنه صادر من الذكاء الاصطناعي.

## تعطل مصدر خارجي

إذا تعذر الوصول إلى أحد المصادر، لا يُحوّل العطل التقني إلى:

- ضعيف.
- موضوع.
- لم يُعثر عليه.

بل يعرض النظام أن التحقق تعذر تقنيًا عندما تكون الخدمة المطلوبة غير متاحة.

## عدم العثور على الحديث

تعرض حالة:

```text
لم يُعثر عليه
```

فقط عندما تنجح عملية البحث ولا يوجد تطابق كافٍ.
