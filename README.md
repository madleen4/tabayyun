# تَبَيَّن

**تثبّت من صحة الأحاديث قبل نشرها.** تلصق منشوراً أو خطبة، أو ترفع ملف Word / PDF / صورة، فيحدد تَبَيَّن الأقوال المنسوبة إلى النبي ﷺ، ويبحث عنها في المصادر المعتمدة، ويعرض حالة الحديث ومصدره، ويكشف اختلاف اللفظ، ثم يساعد المستخدم على إخراج نص مصحح موثق.

مشاركة في **تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي** — المسار الرابع: أدوات المعرفة والتحقق لتمكين المعرّفين بالإسلام.

- **الرابط المباشر:** https://tabayyun-oats.onrender.com
- **صفحة اختبار الحالات:** `/cases.html`

> تَبَيَّن أداة مساعدة، وليست مرجعاً شرعياً، ولا تُصدر حكماً شرعياً من عندها. ألفاظ الأحاديث ودرجاتها تُؤخذ من المصادر، ويُستخدم الذكاء الاصطناعي في المهام اللغوية المساندة فقط.

---

## المشكلة

قد تنتشر نصوص منسوبة إلى النبي ﷺ وهي ضعيفة أو موضوعة أو منقولة بلفظ محرّف. والتحقق اليدوي يتطلب استخراج كل حديث والبحث عنه ومقارنة لفظه وتوثيق مصدره. كما أن النموذج اللغوي العام قد يختلق حكماً أو مصدراً إذا استُخدم وحده.

## آلية العمل

| الخطوة | ما يحدث |
| --- | --- |
| 1. الإدخال | لصق نص أو رفع Word / PDF / صورة. |
| 2. الاستخراج | نموذج لغوي يحدد مواضع الأحاديث في النص، مع قواعد احتياطية إذا تعذّر النموذج. |
| 3. التحقق | البحث في **الدرر السنية** مباشرة عبر واجهة JSON/JSONP المعلنة، وبالتوازي في **HadeethEnc** للأحاديث الثابتة والمطابقة. |
| 4. الحالة | تحويل أحكام المصدر بقواعد مكتوبة إلى: ثابت، ضعيف، موضوع، مختلف فيه، لم يُعثر عليه. |
| 5. كشف التحريف | مقارنة لفظ المستخدم بأقرب لفظ ثابت من المصدر. |
| 6. البدائل | الذكاء الاصطناعي يقترح كلمات بحث فقط، والحديث البديل نفسه يأتي من **HadeethEnc**. |
| 7. التصحيح | المستخدم يختار الاستبدال أو الحذف، ثم يحصل على نسخة مصححة موثقة. |

## المصادر

### 1) الموسوعة الحديثية — الدرر السنية

تُستخدم لعرض **أحكام المحدّثين ومصادرها**، وخصوصاً الضعيف والموضوع والمختلف فيه. الاتصال الأساسي من المتصفح عبر JSONP وفق الواجهة التي تعلنها الدرر لأصحاب المواقع:

- https://dorar.net/article/389
- https://dorar.net/hadith

لا يخزن تَبَيَّن نتائج الدرر ولا يعيد بناء قاعدة بيانات منها.

### 2) موسوعة الأحاديث النبوية — HadeethEnc

تُستخدم للأحاديث الثابتة، والمطابقة اللفظية، واقتراح البدائل الصحيحة. التكامل عبر الـ API الرسمي:

- https://hadeethenc.com/ar/
- https://hadeethenc.com/api-docs/

وتُنسب النتائج بوضوح إلى HadeethEnc، ولا يغيّر تَبَيَّن نص الحديث القادم من المصدر.

## ماذا يحدث عند تعطل مصدر؟

- إذا تعذرت الدرر لكن وُجد الحديث في HadeethEnc، يمكن إثبات كونه ضمن الأحاديث الثابتة في HadeethEnc، مع تنبيه أن أحكام الدرر الإضافية لم تُجلب.
- إذا تعذرت الدرر ولم يوجد الحديث في HadeethEnc، **لا يحكم تَبَيَّن بأنه ضعيف أو موضوع**؛ بل يعرض «تعذّر التحقق».
- «لم يُعثر عليه» لا تعني «موضوع»، وإنما تعني أن الأداة لم تجد أصلاً مطابقاً بثقة كافية مع توفر مسار التحقق.

هذا يحقق مبدأ الامتناع عند غياب المرجع بدلاً من توليد حكم غير موثق.

## دور الذكاء الاصطناعي وحدوده

القاعدة: **النموذج لا يكتب نص حديث ولا يقرر درجته.**

| المهمة | دور الذكاء الاصطناعي | الضابط |
| --- | --- | --- |
| استخراج الأحاديث من نص حر | تحديد المقاطع المرشحة | لا يُقبل مقطع غير موجود في نص المستخدم |
| قراءة الصور | OCR | المستخدم يراجع النص قبل التحقق |
| اقتراح البدائل | اقتراح كلمات بحث فقط | نص البديل يأتي من HadeethEnc |
| تحسين الصياغة | تعديل كلام الكاتب حول الحديث | لفظ الحديث نفسه محمي من التعديل |
| الحكم والمطابقة | لا يستخدم النموذج | قواعد برمجية + بيانات المصادر |

## الخصوصية

- لا تُحفظ نصوص المستخدم في قاعدة بيانات.
- Word وPDF يُقرآن في المتصفح قدر الإمكان.
- مفتاح Gemini يبقى في الخادم ولا يصل إلى المتصفح.
- نصوص البحث تُرسل إلى المصادر اللازمة للتحقق فقط.
