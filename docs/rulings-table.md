# جدول تحويل أحكام المحدِّثين إلى الحالات الخمس

هذا الجدول هو القاعدة الوحيدة التي تحدد بها الأداة الحالة، وهو مكتوب في `src/classify.js`.
**يُعرض على المرشد الشرعي للمراجعة**، وتوثَّق ملاحظاته وما عُدّل بناءً عليها في آخر هذا الملف.

## 1) تصنيف عبارة الحكم الواحدة

| الفئة | العبارات (بعد حذف التشكيل) | ملاحظة |
| --- | --- | --- |
| ثابت | صحيح، حسن، ثابت، صححه، حسنه، جيد، رجاله ثقات، متفق عليه، صحيح لغيره، حسن لغيره؛ أو كون المصدر صحيح البخاري أو صحيح مسلم | |
| ضعيف | ضعيف، ضعيف جداً، منكر، واه، متروك، مرسل، منقطع، معضل، شاذ، معلول، مضطرب، خطأ، لا يعرف، ليس بالقوي، لين، فيه ضعف، فيه نظر | |
| ضعيف | لا يصح، لا يثبت، لم يصح، ليس بصحيح، غير صحيح | النفي يُفحص قبل كلمة «صحيح» |
| ضعيف (في الإسناد) | متهم بالوضع، وضّاع، كذاب | اتهام راوٍ ليس حكماً بوضع المتن |
| موضوع | موضوع، مكذوب، كذب، باطل، لا أصل له، ليس له أصل، مختلق | |
| بلا فئة | ما لا يتضمن شيئاً مما سبق | لا يدخل في الحكم |

**مستوى الحكم:** إذا تضمنت العبارة «إسناده، إسناد، رجاله، سنده، طريق، فيه، مرسل، منقطع، متروك، متهم» عُدّ الحكم على **الإسناد**، وإلا فهو على **المتن**.

## 2) تحديد حالة الحديث من مجموع الأحكام المطابقة

| الأحكام المطابقة للحديث | الحالة |
| --- | --- |
| لا يوجد نص مطابق بثقة كافية (التشابه أقل من 60%) | لم يُعثر عليه |
| نصوص مطابقة بلا حكم صريح | لم يُعثر عليه |
| أخرجه البخاري أو مسلم في صحيحه، ولو ضُعّفت طرق أخرى | ثابت (مع تنبيه، والأحكام كلها معروضة) |
| حكم بالثبوت + حكم بالضعف أو الوضع على المتن | مختلف فيه (تُعرض الأحكام كلها دون ترجيح) |
| حكم بالثبوت، وتضعيف لبعض الأسانيد فقط | ثابت (مع تنبيه أن بعض أسانيده ضُعّفت) |
| أحكام بالوضع لا تقل عن أحكام الضعف | موضوع |
| أحكام ضعف أكثر من أحكام الوضع | ضعيف (مع تنبيه إن حكم بعضهم بوضعه) |
